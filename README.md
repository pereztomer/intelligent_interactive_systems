# PDF Presentation Viewer

A simple React application for viewing PDF presentations locally with no backend needed. Upload a PDF file and browse through the pages with full design preservation.

## Features

- Upload and view PDF files
- Navigate between pages
- Zoom in/out functionality
- Page thumbnails for quick navigation
- Preserves original design, layout, and formatting

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser and visit the URL shown in the terminal (usually `http://localhost:5173`)

4. Upload a PDF file to view it!

## Project Structure

- `src/App.jsx` - Main PDF viewer component
- `src/main.jsx` - Entry point
- `index.html` - HTML template
- `vite.config.js` - Vite configuration

## Build for Production

To create a production build:
```bash
npm run build
```

The built files will be in the `dist` folder.
