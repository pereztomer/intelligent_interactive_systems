# Interface

## Core Components

The Presentation Rehearsal Coach interface consists of four primary components that support the complete practice workflow. The **Session Management** component enables users to create, view, and organize multiple practice sessions, each representing a distinct presentation topic or occasion. The **PDF Viewer** component displays presentation slides with standard navigation controls (page navigation, zoom), allowing users to practice with their actual presentation materials. The **Recording Interface** captures both screen content (for slide visibility) and audio (for speech analysis) simultaneously, while automatically tracking navigation events (page changes, time spent per slide) during recording. The **Analysis Dashboard** presents feedback through two views: attempt-level feedback showing immediate metrics (pacing, filler words, pauses) and AI-generated coaching insights, and session-level analysis displaying trends across multiple practice attempts.

## Supported Tasks

Users can perform three main tasks supported by the interface. **Practice Recording** allows users to upload a PDF presentation, navigate through slides while speaking, and record their practice attempt with automatic tracking of slide transitions and timing. The system captures audio, screen content, and navigation patterns in a single recording session. **Performance Analysis** enables users to review individual attempts, viewing both objective metrics (words per minute, pause durations, filler word counts) and AI-generated contextual feedback that explains what the metrics mean and how to improve. **Progress Tracking** supports users in monitoring improvement over time through session-level analysis that identifies trends, persistent issues, and areas of progress across multiple practice attempts within a session.
